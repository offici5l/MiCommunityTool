## Apply
**Automatically submits the Xiaomi bootloader unlock request to get permission.**

Install dependencies:
```bash
pip install micommunity

```
Download [apply.py](https://raw.githubusercontent.com/offici5l/MiCommunityTool/main/script/apply.py) and run it:
```bash
python apply.py
```

___

**Note:**
 * **Termux:** Set **Battery & Data usage** to **"Unrestricted"** and enable **wakelock** (via notification or termux-wake-lock command).
 * **PC (Windows/Linux/macOS):** Ensure the device stays awake and does not enter **Sleep** or **Hibernate** mode.
